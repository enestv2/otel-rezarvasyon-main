## Risks & open questions

- **Timezone database/platform support:** `Europe/Istanbul` conversion must work on supported deployment environments. Recommendation: use `TimeZoneInfo` with the IANA ID and cover it in a renderer-level assertion; if the target runtime lacks the ID, map to its Windows equivalent without changing the displayed time.
- **Page-two drift from shared QuestPDF styles:** shared header/footer or global style edits can silently change page 2. Recommendation: keep all new styles scoped to first-page elements and require before/after rendered-page comparison.
- **Dynamic card overflow:** long venue/hotel names and prices can consume vertical space. Recommendation: allow name wrapping, keep metrics conditional and compact, and avoid fixed card heights; verify 5-hotel input still renders the expected two recommendation cards without clipping.
- **Existing working-tree edits:** renderer, tests, and 0009 spec/plan already contain user changes. Recommendation: preserve and build on those edits; do not reset, overwrite, or rewrite the 0009 files.
