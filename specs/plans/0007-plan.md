# Plan 0007 — Etkinlik kapsamı ve Geoapify konum servisleri

## Yaklaşım
- Mevcut JSON ve PDF endpoint'lerinin ortak `RecommendationRequestDto` sözleşmesini personel ve etkinlik
  şehir/ülke alanlarıyla genişlet. Domain/application request ve doğrulama katmanlarına aynı alanları taşı.
- Geoapify geocoder adapter'ı yapılandırılmış `name`, `city`, `country` girdileriyle çalışsın; etkinlik
  yeri ve otel adları aynı şehir/ülke bağlamında aransın. Koordinat sırası ve aday seçimi için provider
  DTO'su Infrastructure içinde kalsın.
- Geoapify Routing adapter'ı mevcut `IRouteDistanceProvider` sözleşmesini uygulasın. Araç modu, metre,
  saniye ve GeoJSON geometri mevcut `RouteOutcome` modeline eşlensin; hata sınıfları korunup geometri
  doğrulaması mevcut kurallarla yapılsın.
- Geocoding cache bağlamını (provider, normalize edilmiş yer adı, normalize şehir ve ülke) anahtara kat.
  Depolama arayüzü/şeması ve migration/TTL etkisini geriye dönük güvenli şekilde ele al; eski kayıtları
  yeni bağlamla eşleşmiş varsayma.
- Tek `Geoapify:ApiKey` gizli ayarı geocoding, routing ve static map adaptörlerine geçir. Nominatim'in
  User-Agent ve rate-limit gereksinimlerini Geoapify'ye taşımadan, sağlayıcıya özgü rate limit/time-out/
  retry politikalarını ayrı adapter'larda tanımla. URL/query loglamasını maskele.
- Konfigürasyonla eski akış, shadow karşılaştırma ve Geoapify ana akış modlarını ayır. Shadow sonuçları
  yalnız güvenli metrik/uyarı olarak karşılaştırılsın; isim, sicil, ad/soyad veya API anahtarı loglanmasın.
  Fark ölçümünde provider çağrı maliyetini ve geçişin rollback yolunu dokümante et.
- Personel alanlarını PDF rapor modeline gerekli asgari kapsamda taşı; PDF'de sicil/ad/soyadı göster.
  JSON response sözleşmesine ve uygulama/provider loglarına ekleme.
- Geocoding/routing adapter kontrat testleri, request validation testleri, orchestration/cache testleri,
  controller JSON+PDF entegrasyon testleri ve options/secret masking testleri ekle; docs + ADR güncelle.

## Riskler ve kararlar
- Geoapify geocoding yapılandırılmış şehir/ülke araması yapar; belirsiz yer adlarında doğruluğu garanti
  etmez. Ülke adı biçimini API sözleşmesinde netleştir; sağlayıcının ülke filtresi ISO alpha-2 kodu
  beklediğinden, serbest metin ülke adıyla filtreleme varsayma.
- Şehir/ülke değişince eski cache sonucu kullanılmamalı; yeni cache kimliği ve mevcut Mongo indeks/TTL
  davranışı test edilmelidir.
- Shadow mod iki provider ailesine ilave çağrı/maliyet getirir. Kısa süreli, feature flag ile açık ve
  kapalı çalıştırılabilir tasarla; kalıcı dual-run varsayılan olmasın.
- Geoapify API key query parametresi olarak gönderilir; HTTP telemetry, exception ve debug loglarında
  URI redaksiyonu zorunludur. Kullanıcı sohbetinde açıkça paylaşılmış mevcut anahtar rotate edilmelidir.
