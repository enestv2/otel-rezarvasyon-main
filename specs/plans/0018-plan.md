## Diagnosis
`GeoapifyGeocodingProvider` sends `limit=1` and uses the first returned coordinate without confirming that the result identifies the requested venue. `RecommendationReportService` passes that coordinate directly to the map. Separately, `HostedStaticMapProvider` includes route geometries in the Geoapify static-map request, `SchematicStaticMapProvider` draws marker paths, and the PDF legend describes the routes. This plan validates the venue result and removes only route strokes from the map presentation.

## Risks & open questions
- A provider may return a localized or abbreviated place name. Recommendation: normalize case and whitespace and require a meaningful name match; if no candidate is identifiable, return no geocoding result rather than place the pin at an unchecked location.
- Removing route strokes reduces path detail in the PDF. Recommendation: preserve all distance/time text and hotel markers, as requested, and remove only the now-misleading route legend.
- The reference screenshot does not expose an exact coordinate. Recommendation: do not hard-code a point; validate candidate identity and leave coordinate selection to the geocoding result.
