## Files to change or add
- `backend/src/RPAOtelRezervasyon.Api/Program.cs` — OpenAPI belge kaydı, belge/UI eşlemesi, Development ortamı koşulu ve anonim dokümantasyon erişimi.
- `backend/src/RPAOtelRezervasyon.Api/OpenApi/ApiKeySecurityDocumentTransformer.cs` — mevcut API key güvenlik şemasının OpenAPI 10 API'siyle uyumunu gerektiğinde düzeltme.
- `backend/src/RPAOtelRezervasyon.Api/Controllers/RecommendationsController.cs` — operasyon açıklaması ve OpenAPI'nin göstereceği yanıt metadata'sı.
- `backend/src/RPAOtelRezervasyon.Api/RPAOtelRezervasyon.Api.csproj` — yalnızca mevcut bağımlılıkların eksik olduğu doğrulanırsa OpenAPI/Swagger UI paket referansları.
- `backend/tests/RPAOtelRezervasyon.IntegrationTests/` — OpenAPI, UI, auth metadata ve ortam kapsamı için entegrasyon testleri (mevcut test yerleşimi/altyapısına uygun dosyalar).

## Ordered steps
1. Mevcut .NET 10 OpenAPI ve Swagger UI paketlerinin API'lerini doğrula; var olan transformer'ı derlemeye uygun hâle getir.
2. OpenAPI v1 belgesini kaydet; transformer'ı bağla; geliştirme ortamında `/openapi/v1.json` ve `/swagger` sun, dokümantasyon rotalarını anonim yap.
3. Öneri operasyonunun özet/açıklama ve 200, 400, 401, 422 yanıt metadata'sını belgeye ekle; request/response şemalarının doğru görünmesini sağla.
4. Entegrasyon testlerinde geliştirme ortamında belge içeriğini, UI erişimini, API key şemasını ve operasyon yanıtlarını doğrula; üretim ortamında iki dokümantasyon rotasının bulunmadığını, API rotasının auth korumasının sürdüğünü doğrula.
5. `scripts/check` çalıştır ve her AC için kanıtı kaydet.

## Risks & open questions
- .NET 10 OpenAPI tipi/sözleşmesi sürüme bağlı olabilir. Öneri: projedeki kurulu paket sürümlerine göre `IOpenApiDocumentTransformer` imzalarını ve JSON çıktısını derleme/testle doğrula; varsayılan sürüm yükseltmesi yapma.
- Üretimde dokümantasyonu kapatmak mevcut operasyon beklentisini değiştirebilir. Öneri: spec kararıyla Development-only uygula; dokümanlar yalnızca geliştirme ortamı içindir.
- Test host ortamı çoğu zaman Development varsayılanına dayanabilir ve Production davranışını yanlışlıkla kanıtlamayabilir. Öneri: `WebApplicationFactory` ortamını iki senaryoda da açıkça ayarla.
