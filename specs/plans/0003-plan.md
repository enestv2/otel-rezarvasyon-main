- Status: Approved

## Files to change or add
- `backend/src/RPAOtelRezervasyon.Api/RPAOtelRezervasyon.Api.csproj` — `UserSecretsId` tanımlamak; API davranışı değişmez.
- .NET yerel User Secrets deposu (proje dışı kullanıcı profili) — Atlas URI’si ve üretilen API key. Secret değerleri depo dosyalarına eklenmez.

## Ordered steps
1. API projesine sabit ve benzersiz `UserSecretsId` ekle.
2. Kullanıcının verdiği Atlas parolasını URI userinfo için RFC uyumlu encode et; host `cluster0.iavhyaj.mongodb.net`, kullanıcı `cyneai06_db_user`, veritabanı `rpaotelrezarvasyon` olsun.
3. CSPRNG ile güçlü API key üret.
4. `dotnet user-secrets set` ile `Mongo:ConnectionString` ve `Api:ApiKey` değerlerini kullanıcı profilindeki secret store’a yaz.
5. Değerleri göstermeden secret store’da iki ayarın varlığını, Mongo URI host/kullanıcı/db bileşenlerini ve API key uzunluğunu doğrula; git’e sır girmediğini kontrol et.

## Risks & open questions
- User Secrets dosyası proje kökünün dışındaki kullanıcı profilinde tutulur. Öneri: yalnızca bu gerekli kullanıcı profili yazımını yap; değerleri hiçbir terminal çıktısına dökme.
- URI parolasında özel karakterler olabilir. Öneri: parolayı URI userinfo için percent-encode et; ham parolayı config formatında elle birleştirme.
- API key sonradan tekrar gösterilemeyebilir. Öneri: üretimden sonra kullanıcıya bir kez göster ve yerel secret store’a yaz.
