## Ordered steps
1. Bu plan icin insan onayi al; onaydan once uygulama kodu yazma.
2. Domain tarafinda LLM aciklama portunu ve PDF modelinin aciklama alanini ekle; OpenAI tiplerini cekirdege tasima.
3. Infrastructure'da OpenAI uyumlu Chat Completions streaming adapter'i olustur; CancellationToken, timeout, output token limiti ve secret-safe log kurallarini uygula. Modelden serbest metin degil secilen otel ve sinirli gerekce kodlari al. Serbest metin cikarma; sadece secilen otel adi ve gerekce kodlarini parse et.
4. Tum ranked hotel verisi, secim gerekcesi, fiyat/metrikler ve unresolved listesinden PII icermeyen LLM baglami kur.
5. Model cikisini sinirli JSON ile al; secilen otel kimligini ve sunucunun sonuc verisinden hesapladigi izinli reason code'lari dogrula. PDF cumlelerini bu kodlar ve kanonik metriklerden sunucuda olustur; serbest model metni rapora asla girmez. Hata/iptal/bozuk cikti halinde deterministik gerekceyi kullan.
6. QuestPDF'de aciklamayi onerilen otel bolumune ekle; JSON endpoint ve JSON DTO'yu degistirme.
7. `launchSettings.example.json` icine secretsiz Llm ayarlarini ekle; gercek API key'i yalniz ignored yerel launch settings/User Secrets'ten oku, production modelini Rancher Secret dokumante et.
8. Fake streaming adapter ile stream birlesimi, dogrulama, prompt kurallari, fallback, PDF metni, PII dislama, iptal ve JSON uyumlulugunu test et.
9. Bagimsiz read-only inceleme yap ve `scripts/check` calistir; kanitlari spec'e isle.

## Risks & open questions
- LLM serbest metinde olgusal olmayan iddia uretebilir. Oneri: serbest metni kabul etme; modelden yalniz secilen otel ve hesaplanmis izinli reason code'lari al; PDF metnini kanonik veriden sunucuda kur.
- Saglayici protokolu farklilik gosterebilir. Oneri: OpenAI uyumlu Chat Completions streaming protokolune baglan ve BaseUrl/Model'i config'e al; custom protokol adapter kapsam disi.
- Dis servise is verisi gonderilir. Oneri: tum otel sonuc verisini kullanici talebine gore gonder; sicil/ad/soyad, API key ve log/konusma gecmisi gonderme veya saklama. Saglayici veri saklama kosullari secilecek provider'a gore deploy oncesi ayrica degerlendirilmeli.
- Gercek model adi ve endpoint belli degil. Oneri: kodda sabitleme; kullanici local launchSettings/Rancher Secret ortaminda belirlesin. Onay sonrasi gercek degerleri kullanicidan istemeden secret uretme.
- Token stream edilip parca geldikce dogrudan PDF'ye yazilamaz. Oneri: provider stream'ini sunucuda tamponla, tamamlama ve dogrulamadan sonra PDF olustur; V1'de istemciye SSE acma.
